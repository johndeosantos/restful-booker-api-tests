# RESTful Booker - API Testing Collection

## Project Overview

This repository contains a Postman collection for testing the RESTful Booker API.

The collection is designed to validate API functionality through positive and negative test scenarios, including authentication, booking creation, retrieval, updating, and deletion.

## Target Environment

**API Documentation:** https://restful-booker.herokuapp.com/apidoc/index.html

**Base URL:** https://restful-booker.herokuapp.com

## Tools Used

- **Postman** - API testing and request execution
- **RESTful Booker API** - Target API
- **GitHub** - Version control and collection sharing

## Collection Contents

The collection covers the following API operations:

- Authentication
- Create a booking
- Retrieve booking details
- Update an existing booking
- Delete a booking
- Validate API responses and error handling

## How to Import and Run

1. Download the Postman collection JSON file from this repository.
2. Open Postman.
3. Click **Import**.
4. Select the downloaded JSON file.
5. Open the imported collection.
6. Configure the required collection variables.
7. Execute individual requests or run the entire collection using Collection Runner.

## Test Coverage

The collection includes:

- Positive test scenarios for API operations.
- Negative test scenarios for invalid or unauthorized requests.
- HTTP status code validation.
- Response body and data validation.
- Authentication and booking workflow validation.

## Project Purpose

This project demonstrates practical API testing skills, including request configuration, response validation, test scripting, negative testing, and Postman collection management.
